# Abstract

This project presents a Hybrid LDA-BERT Topic Modeling system, serving as a comprehensive demonstration of probabilistic reasoning and representation learning. Designed to align with the core syllabus of 22AIE301 (Probability and Reasoning), the system integrates advanced language models (BERT) with classical probabilistic graphical models. We frame the core Latent Dirichlet Allocation (LDA) model as a **Bayesian Network**, exploring both **Exact and Approximate Inference** techniques. Specifically, we implement **Markov Chain-Monte Carlo (MCMC)** via Gibbs sampling to infer the latent topic distributions, navigating **Uncertain Knowledge Representation**.

Beyond static topic extraction, the project employs **Hidden Markov Models (HMMs)** and the **Kalman Filter** to model the temporal evolution and dynamic smoothing of topic prevalence. We capture complex topic co-occurrences using **Markov Random Fields (MRFs) & Markov Networks**, utilizing **Message Passing** (Belief Propagation) for efficient inference and exploring **Learning in Markov Networks**. Finally, we bridge probabilistic inference and action through **Decision Networks**, computing Expected Utility and Value of Information to optimize research topic selection. This hybrid approach not only achieves high topic coherence but also provides a holistic, rigorous implementation of the 12 core probabilistic reasoning topics.
